## 🧩 Description

Bienvenue sur le dépôt de mon **portfolio personnel**. 

Ce projet a été conçu pour présenter mon parcours, mes compétences et mes réalisations de manière interactive. Il se distingue par son **identité visuelle forte** inspirée de l'univers **Rétro-Gaming / Arcade** (Police pixelisée, couleurs néons, animations CSS).

L'objectif est de démontrer mes capacités techniques en **intégration web** (HTML/CSS) et en **scripting** (JavaScript) sans utiliser de framework lourd, pour une performance optimale et une maîtrise totale du code.

## ✨ Fonctionnalités Clés

Ce portfolio intègre plusieurs fonctionnalités techniques et ergonomiques :

- 🎨 **Design Rétro & Néon** : Utilisation de la police *Press Start 2P*, dégradés animés et ombres portées style "glitch".
- 📱 **100% Responsive** : Adaptation fluide sur mobile, tablette et desktop.
- 🍔 **Menu Burger Animé** : Navigation optimisée pour mobile avec effet de flou (glassmorphism) et animation d'ouverture verticale.
- 🎬 **Animations au scroll** : Utilisation de l'API `IntersectionObserver` pour faire apparaître les éléments de la timeline et les compétences lors du défilement.
- 📝 **Formulaire stylisé** : Interface de contact intégrée au thème graphique.

## 📂 Structure du Projet

Le site est organisé en une page unique (`One Page`) pour une navigation fluide :

| Section | Contenu |
| :--- | :--- |
| **Header** | Navigation sticky et identité visuelle. |
| **À propos** | Présentation personnelle et photo de profil animée. |
| **Compétences** | Listing technique (Langages, Réseaux, Outils). |
| **Passion** | Centres d'intérêt (F1, Gaming, Tech). |
| **Formation** | Timeline verticale du parcours académique (EPITECH, BTS CIEL, BAC Pro). |
| **Expérience** | Chronologie des stages et expériences professionnelles. |
| **Projets** | Cartes de présentation des réalisations (Python, Automatisation...). |
| **Contact** | Liens sociaux, téléchargement du CV et formulaire. |
